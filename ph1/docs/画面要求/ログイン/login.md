## 要素ツリー

- `<header>` 共通ヘッダー（未ログイン状態: ログインボタンなし）
- `<main>` 中央寄せレイアウト（min-h-[70vh] flex items-center）
  - `<div>` ログインカード（max-w-md）
    - `<h1>` 「ログイン」
    - `<div>` メールアドレス入力
      - `<label>` ラベル
      - `<input type="email">` メールアドレス
      - `<p>` バリデーションエラーメッセージ（条件付き表示）
    - `<div>` パスワード入力
      - `<label>` ラベル
      - `<input type="password">` パスワード
      - `<button>` 👁 パスワード表示切替
      - `<p>` バリデーションエラーメッセージ（条件付き表示）
    - `<div>` 認証エラーメッセージ（条件付き表示）
      - ⚠ 「メールアドレスまたはパスワードが正しくありません」
    - `<button>` 「ログイン」
    - `<button>` ローディング状態（disabled + スピナー）
- `<footer>` 共通フッター

## 要件チェックリスト

### フォーム入力
- [ ] メールアドレス入力欄（type="email"）
- [ ] パスワード入力欄（type="password"）
- [ ] パスワード表示/非表示の切替（👁 / 🙈）

### バリデーション
- [ ] メールアドレス: 空チェック + メール形式チェック
- [ ] パスワード: 空チェック
- [ ] エラー時は入力欄を赤枠（border-red-400）+ エラーメッセージ表示

### 認証処理
- [ ] ログインボタンクリックで認証API を呼び出し
- [ ] API 呼び出し中はローディング状態（スピナー + disabled）
- [ ] 認証成功時: JWT トークンを保存 → 認証Context を更新 → TOP画面へ遷移
- [ ] 認証失敗時: エラーメッセージ「メールアドレスまたはパスワードが正しくありません」を表示

### 画面遷移
- [ ] ログイン成功後はTOP画面へ遷移
- [ ] 認証ガード経由のリダイレクト時は、元の遷移先に戻す（任意）
