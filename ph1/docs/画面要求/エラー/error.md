# エラー表示

> 参照: [error.html](./error.html)

## 概要

API通信エラー発生時に表示するエラー状態のデザイン。
専用のエラーページではなく、各画面内にインラインで表示する。

## 要素ツリー

- `<header>` 共通ヘッダー
- `<main>`
  - `<div>` エラーコンテナ（中央寄せ、縦方向中央配置）
    - `<div>` アイコン（エラー種別に応じて切替）
      - 404: 🔍（検索アイコン）
      - 500: ⚠️（警告アイコン）
    - `<h2>` エラータイトル
    - `<p>` エラー説明文
    - `<div>` アクションボタン群
      - `<button>` 再読み込み（500・ネットワークエラー時）
      - `<a>` TOPへ戻る → TOP画面へ
- `<footer>` 共通フッター

---

## エラー種別一覧

| HTTPステータス | アイコン | タイトル | 説明文 | アクション |
|---|---|---|---|---|
| 404 | 🔍 | お探しの商品は見つかりませんでした。 | 削除されたか、URLが間違っている可能性があります。 | TOPへ戻る |
| 500 | ⚠️ | エラーが発生しました | しばらく時間をおいて再度お試しください。 | 再読み込み / TOPへ戻る |

---

## 要件チェックリスト

### 共通
- [ ] エラー表示は各画面のメインコンテンツ領域にインラインで表示（ヘッダー・フッターは維持）
- [ ] エラーコンテナは画面中央に配置（flexbox center）
- [ ] アイコンは大きめに表示（text-6xl 程度）
- [ ] テキストは text-gray-600、タイトルは text-gray-800 で表示

### 404 エラー
- [ ] 商品詳細画面で API が 404 を返した場合に表示
- [ ] 「TOPへ戻る」リンクで TOP画面へ遷移

### 500 サーバーエラー
- [ ] API が 500 系ステータスを返した場合に表示
- [ ] 「再読み込み」ボタンで現在のページをリロード（API再リクエスト）
- [ ] 「TOPへ戻る」リンクで TOP画面へ遷移

### 適用画面
- [ ] 商品詳細画面: 404 / 500
- [ ] TOP画面: 500（商品一覧取得失敗時）
- [ ] 注文履歴画面: 500（注文一覧取得失敗時）
