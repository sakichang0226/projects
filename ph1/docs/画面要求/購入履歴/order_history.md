## 要素ツリー

- `<header>` 共通ヘッダー
- `<main>`
  - `<h1>` 注文履歴
  - 注文あり時:
    - `<div>` 注文リスト
      - `<Disclosure>` (Headless UI) 注文アコーディオン × N
        - `<Disclosure.Button>` 注文ヘッダー
          - `<span>` 📦 アイコン
          - `<p>` 注文番号
          - `<p>` 注文日
          - `<span>` ステータスバッジ（配送済み: green / 処理中: blue）
          - `<span>` 合計金額
          - `<span>` ▼ 開閉矢印
        - `<Disclosure.Panel>` 注文明細
          - `<div>` 商品行 × N
            - `<span>` 商品アイコン + 商品名 × 数量
            - `<span>` 小計
  - 注文なし時:
    - `<div>` 空表示
      - `<p>` 📋 アイコン
      - `<p>` 「注文履歴がありません」
      - `<a>` 「お買い物をはじめる →」→ TOP画面へ
- `<footer>` 共通フッター

## 要件チェックリスト

### 注文一覧
- [ ] API からログインユーザーの注文一覧を取得
- [ ] 注文番号・注文日・ステータス・合計金額を表示
- [ ] 新しい注文が上に来るようにソート

### アコーディオン
- [ ] Headless UI Disclosure で開閉を実装
- [ ] クリックで注文明細の展開/折畳を切り替え
- [ ] 矢印アイコンの回転アニメーション

### ステータスバッジ
- [ ] 配送済み: 緑（bg-green-100 text-green-700）
- [ ] 処理中: 青（bg-blue-100 text-blue-700）

### 注文明細
- [ ] 各商品の商品名・数量・小計を表示

### 空表示
- [ ] 注文がない場合は空表示に切り替え
- [ ] 「お買い物をはじめる →」でTOP画面へ遷移

### 認証ガード
- [ ] 未ログイン時はこの画面にアクセスできない（ログイン画面へリダイレクト）
