## 要素ツリー

- `<header>` 共通ヘッダー
- `<main>`
  - `<h1>` ショッピングカート（件数表示）
  - カート商品あり時:
    - `<div>` 商品リスト
      - `<div>` 商品行 × N
        - `<div>` 商品画像（サムネイル）
        - `<div>` 商品名 + 単価
        - `<div>` 数量変更
          - `<button>` −
          - `<span>` 数量
          - `<button>` +
        - `<p>` 小計（単価 × 数量）
        - `<button>` 🗑 削除
    - `<div>` 合計エリア
      - `<span>` 合計（税込）
      - `<span>` 合計金額
      - `<a>` 「注文手続きへ進む →」→ 注文確定画面へ
  - カート空時:
    - `<div>` 空カート表示
      - `<p>` 🛒 アイコン
      - `<p>` 「カートに商品がありません」
      - `<a>` 「お買い物を続ける →」→ TOP画面へ
- `<footer>` 共通フッター

## 要件チェックリスト

### 商品リスト
- [ ] カートContext から商品一覧を取得して表示
- [ ] 商品画像（サムネイル）・商品名・単価の表示
- [ ] 各商品の小計（単価 × 数量）を表示

### 数量変更
- [ ] −/+ ボタンで数量を増減
- [ ] 最小値: 1（0にする場合は削除扱い or ボタン無効化）
- [ ] 最大値: 商品の在庫数（stock）を上限とする。上限到達時は + ボタンを無効化
- [ ] 数量変更時に小計・合計が即時再計算

### 商品削除
- [ ] 🗑 ボタンクリックでカートから商品を削除
- [ ] 削除後にリスト・合計が即時更新
- [ ] ヘッダーのカートバッジ数が即時更新

### 合計・注文遷移
- [ ] 合計金額（税込）の表示
- [ ] 「注文手続きへ進む →」クリックで注文確定画面へ遷移
- [ ] 未ログイン時は注文手続きボタンでログイン画面へリダイレクト

### 空カート
- [ ] カートが空の場合は空カート表示に切り替え
- [ ] 「お買い物を続ける →」でTOP画面へ遷移
