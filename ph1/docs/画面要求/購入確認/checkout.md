## 要素ツリー

- `<header>` 共通ヘッダー
- `<main>`
  - `<h1>` 注文内容の確認
  - `<div>` 注文明細
    - `<div>` 商品行 × N
      - `<span>` 商品アイコン
      - `<p>` 商品名
      - `<p>` 数量
      - `<p>` 小計
    - `<div>` 合計エリア（bg-gray-50）
      - 小計 / 送料 / 合計（税込）
  - `<button>` 「注文を確定する」
  - `<button>` ローディング状態（disabled + スピナー）
  - 注文エラー表示（エラーコード別に出し分け）:
    - `<div>` エラーカード（bg-red-50 / border-red-200）
      - ⓘ アイコン（red）
      - `<h3>` 「注文の処理に失敗しました」
      - `<p>` エラーコード別のメッセージ:
        - API_ORDER_ERR001: 「カート内の商品が見つかりませんでした。商品が削除された可能性があります。」
        - API_ORDER_ERR002: 「カート内に現在購入できない商品が含まれています。」
        - API_ORDER_ERR003: 「在庫が不足している商品があります。数量をご確認ください。」
        - API_ERR999 / その他: 「システムエラーが発生しました。しばらく時間をおいて再度お試しください。」
      - `<button>` アクションボタン:
        - ERR001/ERR002/ERR003: 「カートへ戻る」→ カート画面へ遷移
        - ERR999/その他: 「もう一度試す」→ 注文APIを再実行
  - 注文完了表示:
    - `<div>` 完了カード
      - ✓ アイコン（green）
      - `<h2>` 「注文が完了しました！」
      - `<p>` 注文番号（数値）
      - `<p>` 確認メール送信メッセージ
      - `<a>` 「TOPへ戻る」→ TOP画面へ
      - `<a>` 「注文履歴を見る」→ 注文履歴画面へ
- `<footer>` 共通フッター

## 要件チェックリスト

### 注文明細
- [ ] カートContext から商品一覧を取得して注文明細を表示
- [ ] 各商品の商品名・数量・小計を表示
- [ ] 小計・送料・合計（税込）を計算して表示

### 注文確定
- [ ] 「注文を確定する」ボタンクリックで注文API を呼び出し
- [ ] API 呼び出し中はローディング状態（スピナー + disabled）
- [ ] 決済はスタブ実装（常に成功を返す）
- [ ] 注文成功時にカートContext をクリア

### 注文完了表示
- [ ] 注文完了後に完了カードを表示（明細を非表示に切り替え）
- [ ] 注文番号の表示（APIレスポンスから取得、数値形式で表示）
- [ ] 「TOPへ戻る」でTOP画面へ遷移
- [ ] 「注文履歴を見る」で注文履歴画面へ遷移

### 注文エラー
- [ ] 注文APIがエラーを返した場合、注文明細の下にエラーカードをインライン表示
- [ ] エラーカード: bg-red-50 / border-red-200 / アイコンred
- [ ] エラーコード別にメッセージを出し分け:
  - [ ] API_ORDER_ERR001: 「カート内の商品が見つかりませんでした。商品が削除された可能性があります。」
  - [ ] API_ORDER_ERR002: 「カート内に現在購入できない商品が含まれています。」
  - [ ] API_ORDER_ERR003: 「在庫が不足している商品があります。数量をご確認ください。」
  - [ ] API_ERR999 / その他: 「システムエラーが発生しました。しばらく時間をおいて再度お試しください。」
- [ ] アクションボタンの出し分け:
  - [ ] ERR001/ERR002/ERR003: 「カートへ戻る」→ カート画面へ遷移
  - [ ] ERR999/その他: 「もう一度試す」→ 注文APIを再実行
- [ ] エラー表示中も注文明細は表示したまま（ユーザーが内容を確認できるように）

### 認証ガード
- [ ] 未ログイン時はこの画面にアクセスできない（ログイン画面へリダイレクト）
