## 要素ツリー

- `<header>` 共通ヘッダー
- `<main>`
  - `<h1>` 注文内容の確認
  - `<div>` 注文明細
    - `<div>` 商品行 × N
      - `<span>` 商品アイコン
      - `<p>` 商品名
      - `<p>` 数量
      - `<p>` 小計
    - `<div>` 合計エリア（bg-gray-50）
      - 小計 / 送料 / 合計（税込）
  - `<button>` 「注文を確定する」
  - `<button>` ローディング状態（disabled + スピナー）
  - 注文完了表示:
    - `<div>` 完了カード
      - ✓ アイコン（green）
      - `<h2>` 「注文が完了しました！」
      - `<p>` 注文番号
      - `<p>` 確認メール送信メッセージ
      - `<a>` 「TOPへ戻る」→ TOP画面へ
      - `<a>` 「注文履歴を見る」→ 注文履歴画面へ
- `<footer>` 共通フッター

## 要件チェックリスト

### 注文明細
- [ ] カートContext から商品一覧を取得して注文明細を表示
- [ ] 各商品の商品名・数量・小計を表示
- [ ] 小計・送料・合計（税込）を計算して表示

### 注文確定
- [ ] 「注文を確定する」ボタンクリックで注文API を呼び出し
- [ ] API 呼び出し中はローディング状態（スピナー + disabled）
- [ ] 決済はスタブ実装（常に成功を返す）
- [ ] 注文成功時にカートContext をクリア

### 注文完了表示
- [ ] 注文完了後に完了カードを表示（明細を非表示に切り替え）
- [ ] 注文番号の表示（API レスポンスから取得）
- [ ] 「TOPへ戻る」でTOP画面へ遷移
- [ ] 「注文履歴を見る」で注文履歴画面へ遷移

### 認証ガード
- [ ] 未ログイン時はこの画面にアクセスできない（ログイン画面へリダイレクト）
