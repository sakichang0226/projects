## 要素ツリー

- `<header>` 共通ヘッダー
- `<main>`
  - `<nav>` パンくずリスト
    - `<a>` TOP → TOP画面へ
    - `<a>` > カテゴリ名（将来のカテゴリページ用、MVPではリンクなし）
    - `<span>` > 商品名
  - `<div>` 2カラムグリッド（md:grid-cols-2）
    - `<div>` 商品画像エリア
      - `<img>` 商品画像（S3 から取得）
    - `<div>` 商品情報エリア
      - `<h1>` 商品名
      - `<p>` 価格（税込）
      - `<div>` 評価（★）+ スコア + レビュー件数
      - `<div>` 数量選択
        - `<button>` −（デクリメント）
        - `<input>` 数量表示（readonly）
        - `<button>` +（インクリメント）
      - `<button>` 🛒 カートに追加する
      - `<div>` 在庫ステータス表示
        - `<span>` 「残りわずか」（stock <= 5 かつ stock > 0）
        - `<span>` 「在庫切れ」（stock === 0 or status === "S"/"D"）
      - `<div>` 商品説明
        - `<h3>` 見出し
        - `<p>` 説明文（description フィールドをそのまま表示）
        - ※ スペック情報（素材・サイズ・カラー等）は description に含めて登録する運用とする
- `<div>` トースト通知（Headless UI Transition）
  - `<span>` ✅ アイコン
  - `<p>` メッセージ（商品名 × 数量）
  - `<button>` ✕ 閉じる
- `<footer>` 共通フッター

## 要件チェックリスト

### パンくずリスト
- [ ] TOP > カテゴリ名 > 商品名 の階層表示
- [ ] TOPリンクでTOP画面へ遷移
- [ ] カテゴリ名はAPIレスポンスの category_name を使用

### 商品情報
- [ ] API から商品IDで商品詳細を取得
- [ ] 商品画像の表示（S3 URL）
- [ ] 商品名・価格（税込）の表示
- [ ] 評価スコア（★表示）+ レビュー件数の表示
- [ ] 商品説明（description）をそのまま表示
  - ※ スペック情報（素材・サイズ・カラー等）は専用フィールドを設けず、description に含めて登録する運用とする

### 数量選択
- [ ] −/+ ボタンで数量を増減
- [ ] 最小値: 1（1未満にならない）
- [ ] 最大値: 在庫数（stock）を上限とする。上限到達時は + ボタンを無効化
- [ ] 数量は readonly 表示

### 在庫・ステータス制御
- [ ] `stock === 0` または `status === "S"（販売停止）` / `status === "D"（削除済み）` の場合、カート追加ボタンを無効化（disabled）
- [ ] ボタン無効時は「在庫切れ」「販売終了」等のラベルに切り替え、グレーアウト表示
- [ ] 在庫残りわずか（stock <= 5 かつ stock > 0）の場合、「残りわずか」ラベルを表示

### カート追加
- [ ] 「カートに追加する」ボタンクリックでカートContext に追加（フロントのみ、バックエンドAPIは不要）
- [ ] 追加成功時にトースト通知を表示（Headless UI Transition）
- [ ] トースト通知は数秒後に自動で消える or ✕ボタンで閉じる
- [ ] ヘッダーのカートバッジ数が即時更新される
- [ ] カートはブラウザの localStorage に永続化し、再訪問時に復元する

### エラーハンドリング
- [ ] API 404（商品が見つからない）の場合、「商品が見つかりません」メッセージを表示
  - メッセージ: 「お探しの商品は見つかりませんでした。削除されたか、URLが間違っている可能性があります。」
  - 「TOPへ戻る」リンクを表示
- [ ] API 500 等のサーバーエラー時は汎用エラーメッセージを表示し、再読み込みボタン / TOPへ戻るリンクを表示
