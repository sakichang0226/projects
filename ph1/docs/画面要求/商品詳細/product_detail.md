## 要素ツリー

- `<header>` 共通ヘッダー
- `<main>`
  - `<nav>` パンくずリスト
    - `<a>` TOP → TOP画面へ
    - `<span>` > 商品名
  - `<div>` 2カラムグリッド（md:grid-cols-2）
    - `<div>` 商品画像エリア
      - `<img>` 商品画像（S3 から取得）
    - `<div>` 商品情報エリア
      - `<h1>` 商品名
      - `<p>` 価格（税込）
      - `<div>` 評価（★）+ スコア + レビュー件数
      - `<div>` 数量選択
        - `<button>` −（デクリメント）
        - `<input>` 数量表示（readonly）
        - `<button>` +（インクリメント）
      - `<button>` 🛒 カートに追加する
      - `<div>` 商品説明
        - `<h3>` 見出し
        - `<p>` 説明文
        - `<ul>` スペック一覧（素材・サイズ・カラー）
- `<div>` トースト通知（Headless UI Transition）
  - `<span>` ✅ アイコン
  - `<p>` メッセージ（商品名 × 数量）
  - `<button>` ✕ 閉じる
- `<footer>` 共通フッター

## 要件チェックリスト

### パンくずリスト
- [ ] TOP → 商品名 の階層表示
- [ ] TOPリンクでTOP画面へ遷移

### 商品情報
- [ ] API から商品IDで商品詳細を取得
- [ ] 商品画像の表示（S3 URL）
- [ ] 商品名・価格（税込）の表示
- [ ] 評価スコア（★表示）+ レビュー件数の表示

### 数量選択
- [ ] −/+ ボタンで数量を増減
- [ ] 最小値: 1（1未満にならない）
- [ ] 数量は readonly 表示

### カート追加
- [ ] 「カートに追加する」ボタンクリックでカートContext に追加
- [ ] 追加成功時にトースト通知を表示（Headless UI Transition）
- [ ] トースト通知は数秒後に自動で消える or ✕ボタンで閉じる
- [ ] ヘッダーのカートバッジ数が即時更新される
